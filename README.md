# Week 9 Lab: Dictionaries and Sorting

## Setup
1. Open this folder in VS Code (the whole folder, not just the notebook).
2. Open `week9_lab.ipynb`.
3. Select the Python kernel if prompted.
4. Complete each task directly in the notebook. Full task instructions and grading details are posted in Blackboard.

## Submitting Your Work
1. Run all cells top to bottom to confirm your code works before submitting.
2. Save the notebook with the outputs showing.
3. Open the Source Control panel in VS Code (branch icon).
4. Stage your changes (+).
5. Commit with a message such as: `feat: Complete Week 9 lab`
6. Sync (push) your changes to GitHub.
7. Copy your repository URL and paste it into the Week 9 Lab assignment in Blackboard.
